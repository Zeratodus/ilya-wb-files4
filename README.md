# ilya-wb-files4

Медиафайлы и шрифты для страницы «Илья Чванов — отзывы о ВЗЧ» на Тильде.
Файлы подключаются через jsDelivr:

https://cdn.jsdelivr.net/gh/Zeratodus/ilya-wb-files4@main/<путь к файлу>

- `img/ilya-chvanov-hero.webp` — фото на первом экране
- `img/ilya-chvanov-about.webp` — фото в блоке «Кто такой Илья Чванов»
- `img/cases/case-*.webp` — карточки кейсов учеников (10 шт.)
- `fonts/unbounded-700.woff2`, `fonts/manrope-var.woff2` — шрифты (кириллица + латиница)

Репозиторий должен быть публичным, иначе jsDelivr не отдаст файлы.
